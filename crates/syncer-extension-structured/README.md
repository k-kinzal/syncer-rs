# syncer-extension-structured

Official native document extension for Syncer. Supports YAML, TOML, HCL, XML, JSONC, JSON5, INI, dotenv, Java properties, CSV, TSV and XML property lists. Select fields with `pointer` and apply shared `set`, `ensure`, `array` and `remove` policies.

See the repository's `docs/formats.md` for each format's selectors, preservation guarantees and supported values.
